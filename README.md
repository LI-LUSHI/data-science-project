# Seoul Bike Sharing Data Analysis

This project performs exploratory data analysis on the Seoul Bike Sharing dataset.
The goal is to investigate how environmental factors affect the number of rented public bikes.

## Project Structure
- `seoul_bike_analysis.ipynb`: Jupyter notebook containing all data cleaning, analysis and visualization code.
- `requirements.txt`: Python package dependencies for this project.
- `pm25_bike_scatter.png`: Scatter plot of PM2.5 concentration vs bike rental count.
- `correlation_heatmap.png`: Correlation heatmap of numerical variables.
